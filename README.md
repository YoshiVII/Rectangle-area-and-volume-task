# Rectangle Area and Volume Task

This program calculates the area of a rectangle when the height is `-1`, or the volume of a box when a height is provided.

## Test evidence

The program was tested with the required inputs:

| Width | Length | Height | Expected output | Actual output |
|---:|---:|---:|---|---|
| 5 | 6 | -1 | `Area = 30` | `Area = 30` |
| 10 | 4 | 0 | `Volume = 0` | `Volume = 0` |
| 3 | 5 | 10 | `Volume = 150` | `Volume = 150` |

### Test 1

Inputs:

```text
5
6
-1
```

Output:

```text
Area = 30
```

### Test 2

Inputs:

```text
10
4
0
```

Output:

```text
Volume = 0
```

### Test 3

Inputs:

```text
3
5
10
```

Output:

```text
Volume = 150
```
